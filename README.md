# Poke-Controller Modified Extension Improved

[Poke-Controller Modified Extension](https://github.com/futo030/Poke-Controller-Modified-Extension)をベースに機能を追加したゲーム機自動化支援ソフトウェアです。

進んだ自動化ソフトウェアである[Pokemon-Automation](https://pokemonautomation.github.io/index.html)のfirmwareである、PaBotBase2形式に対応することで、入手性が高く安いRaspberry Pi Pico2での使用を可能にしています。

## Poke-Controller とは?

Poke-Controllerの概要は[KawaSwitch](https://github.com/KawaSwitch)氏が開発した[Poke-Controller](https://github.com/KawaSwitch/Poke-Controller)および[Poke-Controller Modified](https://github.com/Moi-poke/Poke-Controller-Modified), [Poke-Controller Modified Extension](https://github.com/futo030/Poke-Controller-Modified-Extension)を参照してください。


## Poke-Controller Modified Extensionとの差分について

- PaBotBase2形式Firmwareへの対応
  - Bluetooth経由での操作が可能に
  - Joy-Conとして操作可能に(Let's Go ピカチュウ/イーブイへの対応)
- 色違い音声認識機能の追加
  - 動作検証できてません

## 推奨環境

- OS
  - Windows10/11
- Python
  - 3.12以上
