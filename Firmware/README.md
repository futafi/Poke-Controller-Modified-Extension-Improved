# PABotBase Firmware

The PABotBase firmware is the endpoint program that is flashed to your device to run the Pokémon Automation Computer Control programs.

## Compatibility Target

This project targets PokemonAutomation 0.63.9 PABotBase2 firmware compatibility for the near term.

Bundled Pico firmware target:

- `PABotBase2-Pico2-2026042700.uf2`
- PABotBase2 firmware version: `2026042700`

Protocol compatibility work should continue to preserve this firmware unless we intentionally raise the supported PokemonAutomation baseline.
