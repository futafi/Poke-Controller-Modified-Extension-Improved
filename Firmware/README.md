# PABotBase Firmware

The PABotBase firmware is the endpoint program that is flashed to your device to run the Pokémon Automation Computer Control programs.

## Compatibility Target

This project targets PokemonAutomation v0.64.8-beta PABotBase2 firmware compatibility for the near term.

Bundled PABotBase2 firmware targets:

- `PABotBase2-ESP32-2026051001.bin`
- `PABotBase2-ESP32-S3-2026051001.bin`
- `PABotBase2-Pico1-2026051001.uf2`
- `PABotBase2-Pico2-2026051001.uf2`
- PABotBase2 firmware version: `2026051001`
- PABotBase2 message protocol version: `2026050901`

Protocol compatibility work should continue to preserve this firmware unless we intentionally raise the supported PokemonAutomation baseline.
